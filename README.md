# E-Commerce Marketplace

A simple E-Commerce Marketplace website built using HTML and CSS.

## Project Overview

This project is a basic front-end e-commerce platform that allows users to browse product categories and view featured products in a clean and user-friendly interface.

## Features

- Responsive layout
- Navigation bar
- Product category section
- Featured product cards
- Product images and pricing
- Clean and simple UI
- HTML5 and CSS3 based design

## Products Included

- Wireless Headphones
- Smart Watch
- Sports Shoes

## Technologies Used

- HTML5
- CSS3

## Folder Structure

```text
ecommerce-marketplace/
│
├── index.html
├── style.css
└── images/
    ├── headphones.jpg
    ├── smartwatch.jpg
    └── shoes.jpg
```

## How to Run

1. Download or clone the repository.
2. Open the project folder in VS Code.
3. Open `index.html`.
4. Run using Live Server.
